# Simple Games Collection: Pacman & Snake

This repository contains two classic arcade-style games implemented as simple projects for learning and fun:

- 🟡 **Pacman**
- 🐍 **Snake Game**

---

## 🎮 Games Overview

### 1. Pacman
Control Pacman through a maze, eat all the pellets, and avoid the ghosts!

**Features:**
- Player-controlled Pacman
- Maze with walls and food pellets
- Basic ghost AI (optional)
- Score tracking

### 2. Snake Game
Guide the snake to eat food and grow longer. Don't hit the walls or yourself!

**Features:**
- Classic snake movement
- Random food generation
- Score tracking
- Increasing difficulty

---

## 🛠️ Technologies Used

- Python 3
- Pygame (for graphics and input)
- Basic object-oriented programming
- Optional: HTML/CSS/JS (if web version)

---

## 🚀 Getting Started

### Requirements
- Python 3 installed
- `pygame` module (install with `pip install pygame`)

### Run the Games

```bash
# Clone the repository
git clone https://github.com/yourusername/simple-games

# Navigate to the game directory
cd games

# Run Pacman
python pacman.py

# Run Snake
python snake.py
